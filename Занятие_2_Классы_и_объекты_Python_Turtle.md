# Часть 1. Теория классов с примерами — 50 минут

## 1. Что такое класс и объект? (10 минут)

Представим программу, в которой необходимо описывать автомобили. У каждого автомобиля есть **характеристики** — марка, цвет, скорость — и **действия** — сигналить, ускоряться, останавливаться.

**Класс** — шаблон, который описывает данные и действия будущих объектов.  
**Объект** — конкретный экземпляр класса со своими данными.

Например, `Car` — класс, а конкретные Toyota и BMW — два разных объекта этого класса.

### Пример 1. Самый простой класс

```python
class Car:
    pass


car1 = Car()
car2 = Car()

print(car1)
print(car2)
```

**Объяснение:**

- `class Car:` — объявление класса;
- `pass` — пустое тело класса;
- `Car()` — создание объекта;
- `car1` и `car2` — два разных объекта.

### Пример 2. Добавляем атрибуты

**Атрибут** — переменная, принадлежащая объекту.

```python
class Car:
    pass


car1 = Car()
car1.brand = "Toyota"
car1.color = "Красный"

car2 = Car()
car2.brand = "BMW"
car2.color = "Синий"

print(car1.brand)
print(car2.brand)
```

Результат:

```text
Toyota
BMW
```

**Вопросы студентам:**

1. Что выведет `print(car1.color)`?
2. Если изменить `car2.color`, изменится ли `car1.color`?
3. Чем класс отличается от объекта?

**Вывод:** у каждого объекта могут быть собственные значения атрибутов.

## 2. Метод `__init__` (10 минут)

Если каждый раз вручную задавать атрибуты, код получится длинным. Метод `__init__` автоматически вызывается при создании нового объекта и обычно задаёт его начальное состояние.

```python
class Car:
    def __init__(self, brand, color):
        self.brand = brand
        self.color = color


car1 = Car("Toyota", "Красный")
car2 = Car("BMW", "Синий")

print(car1.brand)
print(car2.color)
```

**Разбор:**

- `__init__` — специальный метод инициализации;
- `self` — ссылка на текущий объект;
- `brand` и `color` — параметры;
- `self.brand` и `self.color` — атрибуты конкретного объекта.

Строка `self.brand = brand` сохраняет переданное значение `brand` в атрибут `self.brand`.

## 3. Методы класса (15 минут)

**Метод** — функция, определённая внутри класса. Методы позволяют объектам выполнять действия.

### Пример 3. Автомобиль сигналит

```python
class Car:
    def __init__(self, brand, color):
        self.brand = brand
        self.color = color

    def signal(self):
        print(self.brand, "сигналит: Би-бип!")


car1 = Car("Toyota", "Красный")
car2 = Car("BMW", "Синий")

car1.signal()
car2.signal()
```

Результат:

```text
Toyota сигналит: Би-бип!
BMW сигналит: Би-бип!
```

Один и тот же метод работает с данными того объекта, у которого его вызвали.

### Пример 4. Метод изменяет состояние объекта

```python
class Car:
    def __init__(self, brand):
        self.brand = brand
        self.speed = 0

    def accelerate(self):
        self.speed += 10

    def show_speed(self):
        print(self.brand, self.speed, "км/ч")


car = Car("Toyota")

car.accelerate()
car.accelerate()
car.accelerate()

car.show_speed()
```

Результат:

```text
Toyota 30 км/ч
```

**Объяснение:** каждый вызов `accelerate()` увеличивает атрибут `speed` на 10.

### Пример 5. Метод с параметром

```python
class Car:
    def __init__(self, brand):
        self.brand = brand
        self.speed = 0

    def accelerate(self, amount):
        self.speed += amount

    def show_speed(self):
        print(self.brand, self.speed, "км/ч")


car = Car("BMW")
car.accelerate(20)
car.accelerate(30)
car.show_speed()
```

Результат:

```text
BMW 50 км/ч
```

**Вопросы студентам:**

- Чем `accelerate(20)` отличается от `accelerate(50)`?
- Почему при вызове `car.accelerate(20)` не передают `self` явно?

### Практическое задание: «Банковский счёт»

Создайте класс `BankAccount`, который хранит владельца и баланс. Реализуйте методы:

- `deposit(amount)` — пополнение баланса;
- `withdraw(amount)` — снятие денег при достаточном балансе;
- `show_balance()` — вывод текущего баланса.

**Пример решения для преподавателя:**

```python
class BankAccount:
    def __init__(self, owner):
        self.owner = owner
        self.balance = 0

    def deposit(self, amount):
        if amount > 0:
            self.balance += amount

    def withdraw(self, amount):
        if 0 < amount <= self.balance:
            self.balance -= amount
        else:
            print("Невозможно снять деньги")

    def show_balance(self):
        print(self.owner, "Баланс:", self.balance)


account = BankAccount("Алексей")
account.deposit(1000)
account.withdraw(300)
account.show_balance()
```

Результат:

```text
Алексей Баланс: 700
```

**Примечание:** если студенты ещё не изучили `if`, преподаватель объясняет проверки устно и выдаёт их в готовом виде.

# Часть 2. Переход к Turtle — 10 минут

Ранее мы создавали черепашку так:

```python
import turtle

t = turtle.Turtle()
t.shape("turtle")
t.color("red")
t.forward(100)

turtle.done()
```

`Turtle` — готовый класс библиотеки, а `t` — его объект. Команды `forward()`, `left()`, `color()` — методы этого объекта.

### Пример. Два независимых объекта Turtle

```python
import turtle

red = turtle.Turtle()
red.shape("turtle")
red.color("red")

blue = turtle.Turtle()
blue.shape("turtle")
blue.color("blue")

red.forward(100)
blue.left(90)
blue.forward(100)

turtle.done()
```

**Вопрос:** почему красная и синяя черепашки двигаются независимо, хотя обе созданы из одного класса?

**Переход к проекту:** мы можем создать собственный класс `Racer`, который использует объект `Turtle` и добавляет поведение участника гонки.

# Часть 3. Практический проект «Гонки черепашек» — 15 минут

**Цель:** создать нескольких участников гонки из одного класса и определить победителя.

## Шаг 1. Создаём класс участника

```python
import turtle
import random

class Racer:
    def __init__(self, color, y):
        self.color = color
        self.t = turtle.Turtle()
        self.t.shape("turtle")
        self.t.color(color)
        self.t.penup()
        self.t.goto(-250, y)

    def move(self):
        distance = random.randint(1, 10)
        self.t.forward(distance)
```

**Разбор:**

- `color` и `y` задают цвет и стартовую высоту;
- `self.t` — отдельный объект `Turtle` у каждого гонщика;
- `random.randint(1, 10)` выбирает случайное расстояние;
- `move()` передвигает черепашку.

## Шаг 2. Создаём участников

```python
red = Racer("red", 100)
blue = Racer("blue", 0)
green = Racer("green", -100)
```

У каждого участника своя черепашка и стартовая позиция.

## Шаг 3. Запускаем гонку

```python
winner = None

while winner is None:
    red.move()
    blue.move()
    green.move()

    if red.t.xcor() >= 250:
        winner = "Красный"
    elif blue.t.xcor() >= 250:
        winner = "Синий"
    elif green.t.xcor() >= 250:
        winner = "Зелёный"

print("Победитель:", winner)

turtle.done()
```

Цикл `while` повторяет движение до определения победителя. Проверка проводится после общего раунда, поэтому при одновременном пересечении финиша приоритет имеет первая проверенная черепашка.

### Полный код игры

```python
import turtle
import random

screen = turtle.Screen()
screen.setup(700, 450)
screen.title("Гонки черепашек")

class Racer:
    def __init__(self, color, y):
        self.color = color
        self.t = turtle.Turtle()
        self.t.shape("turtle")
        self.t.color(color)
        self.t.penup()
        self.t.goto(-250, y)

    def move(self):
        distance = random.randint(1, 10)
        self.t.forward(distance)


def draw_finish():
    line = turtle.Turtle()
    line.hideturtle()
    line.penup()
    line.goto(250, -150)
    line.pendown()
    line.left(90)
    line.forward(350)


draw_finish()

red = Racer("red", 100)
blue = Racer("blue", 0)
green = Racer("green", -100)

winner = None

while winner is None:
    red.move()
    blue.move()
    green.move()

    if red.t.xcor() >= 250:
        winner = "Красный"
    elif blue.t.xcor() >= 250:
        winner = "Синий"
    elif green.t.xcor() >= 250:
        winner = "Зелёный"

print("Победитель:", winner)

turtle.done()
```
