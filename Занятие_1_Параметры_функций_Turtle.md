# Занятие №1. Параметры функций и создание сложных рисунков в Python Turtle

Научиться создавать универсальные функции для рисования фигур разного размера, цвета и положения, а затем объединять их для построения сложного рисунка.

- объяснить разницу между параметром и аргументом;

- использовать параметры вместо фиксированных значений;
- разбивать большой рисунок на небольшие функции;
- размещать фигуры в разных частях окна Turtle.

## 1. Повторение: что такое функция? (0–10 минут)

**Вопрос студентам:** «Как нарисовать три квадрата, не копируя одинаковые команды три раза?»

Напомним функцию, которая рисует квадрат фиксированного размера:

```python
import turtle

t = turtle.Turtle()

def square():
    t.forward(100)
    t.right(90)
    t.forward(100)
    t.right(90)
    t.forward(100)
    t.right(90)
    t.forward(100)

square()

turtle.done()
```

**Обсуждение:**

1. Что делает `def`?
2. В какой момент выполняются команды внутри функции?
3. Что неудобно, если нам нужен квадрат со стороной не 100, а 50 или 200?

**Переход к теме:** функция полезна, но размер здесь «зашит» в её коде. Попробуем сделать функцию, которая умеет рисовать квадраты любого размера.

## 2. Параметры и аргументы функций (10–25 минут)

**Параметр** — это имя переменной, записанное в скобках при определении функции.  
**Аргумент** — конкретное значение, передаваемое функции при вызове.

```python
def square(size):
    t.forward(size)
    t.right(90)
    t.forward(size)
    t.right(90)
    t.forward(size)
    t.right(90)
    t.forward(size)
```

Вызов:

```python
square(50)
square(100)
square(150)
```

Здесь `size` — **параметр**, а числа `50`, `100` и `150` — **аргументы**.

> Если вызывать эти функции подряд из одной и той же точки, квадраты могут накладываться друг на друга. Для рисования рядом друг с другом мы чуть позже научимся перемещать черепашку без линии.

### Полный пример для запуска

```python
import turtle

t = turtle.Turtle()
t.speed(3)

def square(size):
    t.forward(size)
    t.right(90)
    t.forward(size)
    t.right(90)
    t.forward(size)
    t.right(90)
    t.forward(size)

square(50)
square(100)
square(150)

turtle.done()
```

**Объяснение преподавателя:** одна функция заменяет несколько почти одинаковых функций `small_square`, `medium_square`, `big_square`.

### Мини-задание

Попросите студентов изменить аргументы и предсказать результат:

- `square(30)`;
- `square(80)`;
- `square(120)`.

Спросите: «Что случится, если вызвать `square()` без аргумента?» — Python сообщит об отсутствии обязательного аргумента `size`.

## 3. Практика №1. Фигуры разных размеров (25–40 минут)

### Задание 1. Треугольник

Создайте функцию `triangle(size)`, которая рисует равносторонний треугольник. Для поворота используйте 120 градусов.

**Образец решения:**

```python
def triangle(size):
    t.forward(size)
    t.left(120)
    t.forward(size)
    t.left(120)
    t.forward(size)
    t.left(120)
```

Проверка:

```python
triangle(70)
triangle(120)
```

### Задание 2. Круг

```python
def circle(radius):
    t.circle(radius)
```

Проверка:

```python

circle(60)
```

### Задание 3. Прямоугольник

Самостоятельно создайте функцию `rectangle(width, height)`.

**Подсказка:** нужно чередовать две стороны, поворачивая на 90 градусов.

**Образец решения:**

```python
def rectangle(width, height):
    t.forward(width)
    t.right(90)
    t.forward(height)
    t.right(90)
    t.forward(width)
    t.right(90)
    t.forward(height)
    t.right(90)
```

Проверка:

```python
rectangle(150, 80)
rectangle(90, 40)
```

**Важное наблюдение:** функции могут принимать не только один, но и несколько параметров.

## 4. Несколько параметров: цвет, размер и положение (40–50 минут)

### 4.1. Добавляем цвет

```python
def circle(radius, color):
    t.pencolor(color)
    t.circle(radius)

circle(40, "red")
circle(70, "blue")
```

**Объяснение:** порядок аргументов должен соответствовать порядку параметров. В `circle(40, "red")` число `40` попадёт в `radius`, строка `"red"` — в `color`.

### 4.2. Учимся менять положение без рисования линии

```python
def move_to(x, y):
    t.penup()
    t.goto(x, y)
    t.pendown()
```

Пример:

```python
move_to(-200, 100)
circle(40, "red")

move_to(100, 100)
circle(60, "blue")
```

Здесь `x` и `y` — координаты точки на экране. Метод `penup()` отключает рисование при перемещении, `pendown()` снова включает.

### 4.3. Функция с тремя параметрами

```python
def square(size, color, x):
    t.pencolor(color)
    move_to(x, 0)
    t.setheading(0)
    t.forward(size)
    t.right(90)
    t.forward(size)
    t.right(90)
    t.forward(size)
    t.right(90)
    t.forward(size)
    t.right(90)

square(60, "red", -200)
square(100, "green", -80)
square(140, "blue", 80)
```

## 5. Практика №2. Композиция функций (50–60 минут)

**Композиция функций** — это ситуация, когда одна функция вызывает другие. Так можно строить сложный рисунок из простых частей.

Ниже — самостоятельный пример. Квадрат рисуется от **левого нижнего угла**, поэтому крыша начинается на верхней стороне квадрата.

```python
import turtle

t = turtle.Turtle()
t.speed(6)

def move_to(x, y):
    t.penup()
    t.goto(x, y)
    t.pendown()

def square(size, color, x, y):
    t.pencolor(color)
    move_to(x, y)
    t.setheading(0)
    for _ in range(4):
        t.forward(size)
        t.left(90)

def triangle(size, color, x, y):
    t.pencolor(color)
    move_to(x, y)
    t.setheading(0)
    for _ in range(3):
        t.forward(size)
        t.left(120)

def house(size, color, x, y):
    square(size, color, x, y)
    triangle(size, color, x, y + size)

house(100, "blue", -150, -100)
house(70, "green", 50, -100)

turtle.done()
```

**Замечание:** здесь впервые используется короткая запись цикла `for` для повторения сторон. Если студенты ещё не знают циклы, преподаватель может заменить их четырьмя (или тремя) командами `forward` и `left`, как в предыдущих примерах. Цикл в этом занятии не является основной темой.

**Обсуждение:** функция `house()` не рисует каждую сторону самостоятельно, а использует две готовые функции: `square()` и `triangle()`.

## 6. Итоговая работа «Мой город» (60–75 минут)

**Задача:** написать программу, создающую небольшую картину города: дома разного размера, солнце, окна или деревья.

### Обязательные требования

1. Создать функцию `move_to(x, y)` для перемещения без линии.
2. Создать функции для квадрата, треугольника и круга с параметрами.
3. Создать функцию `house(size, color, x, y)`, вызывающую другие функции.
4. Нарисовать не менее **трёх домов** разного размера или цвета.
5. Добавить солнце с помощью `circle(radius, color, x, y)`.

### Рекомендуемый порядок работы

1. Написать и проверить `move_to()`.
2. Написать и проверить простые фигуры.
3. Собрать дом из квадрата и треугольника.
4. Расставить три дома по разным координатам.
5. Добавить солнце, деревья или окна.

### Полный пример итогового рисунка

Пример использует повторение через `for`; его можно дать как образец после самостоятельной попытки или заменить повторяющимися командами для группы, не знакомой с циклами.

```python
import turtle

t = turtle.Turtle()
t.speed(0)

def move_to(x, y):
    t.penup()
    t.goto(x, y)
    t.pendown()

def square(size, color, x, y):
    t.pencolor(color)
    move_to(x, y)
    t.setheading(0)
    for _ in range(4):
        t.forward(size)
        t.left(90)

def triangle(size, color, x, y):
    t.pencolor(color)
    move_to(x, y)
    t.setheading(0)
    for _ in range(3):
        t.forward(size)
        t.left(120)

def circle(radius, color, x, y):
    t.pencolor(color)
    move_to(x, y)
    t.setheading(0)
    t.circle(radius)

def house(size, color, x, y):
    square(size, color, x, y)
    triangle(size, color, x, y + size)
    square(size / 4, "brown", x + size / 3, y + size / 3)

turtle.Screen().setup(850, 500)

house(100, "red", -330, -150)
house(140, "blue", -120, -150)
house(90, "green", 140, -150)
circle(45, "orange", 260, 120)

t.hideturtle()
turtle.done()
```

**На что обратить внимание:**

- `x` и `y` задают положение дома;
- `size` управляет размером корпуса, крыши и окна;
- для каждого дома используется один и тот же вызов `house()` с разными аргументами;
- если изменить реализацию `house()`, изменения затронут все будущие вызовы этой функции.

## Методические рекомендации преподавателю

- Не вводите `return`, области видимости и сложные правила передачи аргументов: для данного занятия достаточно обязательных позиционных параметров.
- Проверяйте новую функцию сразу после её написания. Если студенты допустят ошибку в `move_to()`, она повлияет на все последующие рисунки.
- Если циклы `for` ещё не проходили, оставьте повторение сторон в явном виде. Позже этот код станет удачным примером для темы «Циклы».
- Сравнивайте две версии решения: десятки вручную повторяемых команд и одну функцию с разными аргументами.
- Не требуйте художественной сложности рисунка: главная цель — **понять параметры функций и композицию**, а не освоить сложную графику.

**Итог:** каждый студент создаёт рисунок, собранный из небольших универсальных функций, и видит, как параметры позволяют управлять результатом без переписывания одинакового кода.
