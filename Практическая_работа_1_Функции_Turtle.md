# Практическая работа №1

**Тема:** Функции с параметрами в Python. Графическая библиотека Turtle  
**Продолжительность:** 80 минут  
**Цель:** научиться создавать функции с параметрами, вызывать их с разными аргументами и применять для рисования графических объектов.

## Подготовка к работе

В начале каждой программы подключите библиотеку и создайте черепашку:

```python
import turtle

t = turtle.Turtle()
t.speed(5)
```

В конце программы добавьте:

```python
turtle.done()
```

Для перемещения без рисования используйте:

```python
t.penup()
t.goto(100, 50)
t.pendown()
```

Каждое задание можно выполнять в отдельном файле Python. Если в одном файле рисуется несколько фигур, перемещайте черепашку между ними без линии.

## Часть 1. Простые функции

### Задание 1. Разноцветные линии

Создайте функцию `draw_line(length, color)`, которая рисует линию заданной длины и цвета.

Вызовите функцию три раза:

- Красная линия — 100 пикселей.
- Синяя линия — 150 пикселей.
- Зелёная линия — 200 пикселей.

### Задание 2. Квадраты разных размеров

Создайте функцию `draw_square(size)`, которая рисует квадрат с заданной длиной стороны.

Нарисуйте три квадрата со сторонами 50, 100 и 150 пикселей.

### Задание 3. Прямоугольники

Создайте функцию `draw_rectangle(width, height)`, принимающую два параметра: ширину и высоту.

Нарисуйте следующие прямоугольники:

1. 150 × 80 пикселей.
2. 100 × 100 пикселей.
3. 200 × 50 пикселей.

### Задание 4. Цветные окружности

Создайте функцию `draw_circle(radius, color)`, которая рисует окружность заданного радиуса и цвета.

Нарисуйте три окружности: красную радиусом 30, синюю радиусом 50 и зелёную радиусом 70 пикселей.

## Часть 2. Функции с несколькими параметрами

### Задание 5. Разноцветные треугольники

Создайте функцию `draw_triangle(size, color)`, рисующую равносторонний треугольник заданного размера и цвета.

Нарисуйте три треугольника разных размеров и цветов.

### Задание 6. Пунктирная линия

Создайте функцию `draw_dashed_line(length)`, которая рисует три отрезка одинаковой длины с промежутками между ними.

Параметр `length` определяет длину каждого отрезка. Используйте `penup()` и `pendown()`.

### Задание 7. Разноцветные точки

Создайте функцию `draw_dot(size, color)`, которая рисует закрашенную точку заданного размера и цвета.

Воспользуйтесь командой:

```python
t.dot(size, color)
```

Нарисуйте пять точек разного размера и цвета.

### Задание 8. Перемещение без рисования

Создайте функцию `move_to(x, y)`, которая перемещает черепашку в заданную точку без линии.

Используя эту функцию и `draw_square(size)`, нарисуйте три квадрата в разных местах экрана.

## Часть 3. Создание рисунков с помощью функций

### Задание 9. Светофор

Создайте функцию `draw_light(color, y)`, которая рисует закрашенный круг нужного цвета на заданной высоте.

Нарисуйте светофор с тремя сигналами: красным, жёлтым и зелёным. При желании добавьте прямоугольный корпус.

### Задание 10. Снеговик

Создайте функцию `draw_snowball(radius)`, которая рисует окружность заданного радиуса.

Используйте её три раза, чтобы нарисовать снеговика из трёх окружностей разного размера. Дополнительно можно добавить глаза и нос.

### Задание 11. Воздушные шарики

Создайте функцию `balloon(radius, color)`, которая рисует окружность выбранного цвета и линию вниз в качестве ниточки.

Нарисуйте четыре разноцветных воздушных шарика.

### Задание 12. Домик

Создайте три функции:

- `draw_square(size, color)` — основание дома.
- `draw_triangle(size, color)` — крыша.
- `draw_house(size)` — вызывает обе функции, чтобы нарисовать дом.

Нарисуйте два дома разного размера. Для правильного расположения крыши можно использовать `move_to(x, y)` и повороты черепашки.

## Часть 4. Дополнительные задания

Эти задания предназначены для студентов, выполнивших основную часть раньше остальных.

### Задание 13. Робот

Используя функции для квадратов, прямоугольников и окружностей, создайте рисунок робота.

Робот должен иметь голову, туловище, две руки, две ноги и два глаза.

### Задание 14. Цветок

Создайте функцию `draw_flower(radius, color)`, рисующую цветок из пяти окружностей-лепестков вокруг центральной точки.

Нарисуйте два цветка разного размера и цвета.

### Задание 15. Геометрический узор

Создайте функцию `draw_pattern(size, color)`, которая рисует четыре квадрата, повёрнутых относительно друг друга.

Используйте функцию `draw_square(size, color)` и повороты черепашки.
